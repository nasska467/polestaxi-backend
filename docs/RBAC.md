# Матрица ролевого доступа (RBAC) — PolesTaxi

В данном документе описаны правила доступа к эндпоинтам системы на основе ролей (Role-Based Access Control).

## Роли
*   **User** — пассажир.
*   **Driver** — водитель.
*   **Analyst** — аналитик (доступ к отчетам).
*   **Admin** — администратор (полный доступ).

## Матрица доступа

| Путь / Действие | Метод | User | Driver | Analyst | Admin |
| :--- | :--- | :---: | :---: | :---: | :---: |
| **Аналитика** /v1/analytics/* | GET | ❌ | ❌ | ✅ | ✅ |
| **Профиль водителя** /v1/drivers/* | GET/PATCH | ❌ | ✅ | ❌ | ✅ |
| **Кошелёк** /v1/wallets/* | GET/POST | ✅ | ✅ | ❌ | ✅ |
| **Назначение ролей** /v1/users/{id}/roles | POST | ❌ | ❌ | ❌ | ✅ |
| **Создание заказа** /v1/orders | POST | ✅ | ❌ | ❌ | ✅ |
| **Действия с поездкой** /v1/orders/{id}/accept, decline, start, complete | POST | ❌ | ✅ | ❌ | ✅ |
| **Чтение и отмена заказа** /v1/orders/* | GET/POST | ✅ | ✅ | ✅ | ✅ |
| **GraphQL** /graphql | POST | ✅ | ✅ | ✅ | ✅ |

> *Примечание: Проверка владения заказом (свой/чужой) выполняется внутри Order Service.*
